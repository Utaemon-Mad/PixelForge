# Sprites para mis juegos

Guarda aquí lo que crees con PixelForge:

- `personajes/`, `criaturas/`, `objetos/`, `tilesets/`: PNG a tamaño real (exporta a escala 1×) y su proyecto `.pxf` para poder editarlo después.
- `animaciones/`: spritesheets PNG (frames en horizontal) y GIF de referencia.

Consejo: usa el mismo nombre para el `.pxf` y sus exportaciones (`slime.pxf`, `slime.png`, `slime_sheet_4f.png`).
